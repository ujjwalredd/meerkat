# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## TL;DR

- Be respectful. Critique code, not people.
- Assume good faith.
- No harassment, doxxing, hate speech, or personal attacks.
- Security disclosures go through [SECURITY.md](SECURITY.md), not public threads.

## Reporting

Report violations via GitHub Security Advisories
(<https://github.com/ujjwalredd/meerkat/security/advisories/new>) marked as
"conduct", or by opening a private contact channel with the maintainer.
All reports are reviewed confidentially.

Enforcement follows the Contributor Covenant ladder: correction → warning →
temporary ban → permanent ban.
